**Name:** Agentshive
**Tagline (60 char max):** The open registry for AI agents — free, runs anywhere
**Topics:** Artificial Intelligence, Developer Tools, Productivity, Open Source

**Description:**
Agentshive is a free, open registry of ready-made AI agents. Instead of re-writing the same
prompts, download an agent and run it in Claude Code, Codex, Cursor, Perplexity, n8n,

smart-coder that hands off context between sessions. Install any agent in one command.
